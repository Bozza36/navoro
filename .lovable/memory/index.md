# Project Memory

## Core
Navoro: gamified scenario-based career learning for engineers.
Dark Charcoal #111111 bg, Ivory #FAF9F6 text, Dark Green #064635 primary, Gold #D4AF37 accent, Mint #B7E4C7 secondary. Satoshi font.
Lovable Cloud backend. Auth with email/password. Auto-profile on signup.
7 levels: Explorer→Leader. Nav: Home + Careers (single hub).
Supportive mentor tone. Action-oriented microcopy.
